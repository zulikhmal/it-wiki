# Office Main Router & VLAN Configuration

Standard procedure for resetting and configuring core network hardware.

## 1. Default Access Credentials
* **Gateway IP:** `192.168.1.1`
* **Protocol:** HTTPS

## 2. VLAN Segmentation
* **VLAN 10:** Corporate Workstations
* **VLAN 20:** Guest Wi-Fi (Isolated)
* **VLAN 30:** Printers & Network Storage (NAS)
