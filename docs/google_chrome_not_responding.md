Resolution steps for Google Chrome freezing, becoming unresponsive, or locking up during use.

## 1. Initial Quick Checks
Before reinstalling or altering system files, perform these quick checks:
* **Kill Background Processes:** Press `Ctrl + Shift + Esc` to open **Task Manager**, locate **Google Chrome**, right-click, and select **End Task**. Reopen Chrome to see if responsiveness returns.
* **Clear Browsing Data:** If Chrome launches but freezes immediately, a corrupted cache or extension might be locking the browser. Clear cache and cookies if accessible, or test in Incognito mode (`Ctrl + Shift + N`).

## 2. Reinstall Google Chrome
If the browser application files or user profiles are fundamentally corrupted and basic fixes fail:
1. Open Windows **Settings > Apps > Installed apps** (or *Apps & Features*).
2. Locate **Google Chrome**, click the three dots (`...`), and select **Uninstall**.
3. *Optional (Deep Clean):* Open File Explorer and check `C:\Users\%username%\AppData\Local\Google\Chrome` to clean out lingering profile cache or temp files.
4. Download the latest installer from the official website and reinstall Google Chrome fresh.
