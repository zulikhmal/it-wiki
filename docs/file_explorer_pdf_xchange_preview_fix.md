# File Explorer PDF-XChange Preview Fix

Standard procedure for resolving missing PDF preview pane issues in Windows File Explorer when PDF-XChange is the default viewer.

## 1. Initial Troubleshooting
- **Issue:** Preview Pane not showing PDF thumbnails or contents.
- **Action:** Reinstall PDF-XChange to ensure shell extension components are correctly registered.

## 2. Re-enabling Preview & Thumbnails
- **Step 1:** Open PDF-XChange Editor.
- **Step 2:** Press `Ctrl + K` to open Preferences.
- **Step 3:** Navigate to **File Associations** and enable the options for **Preview** and **Thumbnail**.
